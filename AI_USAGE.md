# EpiScope – AI Usage Documentation

## 1. AI and Development Tools Used

The following tools were used during the development of the EpiScope project:

- **ChatGPT:** Used for coding guidance, technical explanations, debugging, and documentation.
- **Claude:** Used for code assistance, problem-solving, and understanding technical concepts.
- **GitHub Copilot:** Used for code suggestions, auto-completion, and improving coding productivity.
- **Visual Studio Code:** Used as the primary code editor and development environment.
- **GitHub:** Used for source code management, version control, and team collaboration.

## 2. Areas of AI Assistance

AI tools supported the development team in:

- Project planning and module organization.
- Python and PySpark coding assistance.
- Data processing and analytics guidance.
- Debugging and error resolution.
- Dashboard development guidance.
- Preparing project documentation.

## 3. Responsible AI Usage

- AI-generated suggestions were reviewed and modified according to project requirements.
- Code was tested before being included in the project.
- AI tools were used as supporting resources, not as replacements for team members' work.
- The team is responsible for the final code, testing, and project results.
